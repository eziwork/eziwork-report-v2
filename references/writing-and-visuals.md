# 작성과 시각화 기준

- 제목은 고객 질문에 대한 확인된 답을 말한다. ‘가격 분석’보다 실제 비교 결과를 쓴다.
- 본문은 자연스럽게 설명한다. ‘자료상 관찰된다’, ‘판단하지 않았다’ 같은 자기 설명이나 모호한 형용사로 문단을 채우지 않는다.
- 확인하지 않은 조망·수리·공실을 소개한 뒤 알 수 없다고 끝내지 않는다. 질문에 필요한 실제 비교·활용을 남긴다.
- 핵심 수치·조건만 노란 형광펜으로 강조한다. 강조색을 투자 권고나 확실성 표시로 사용하지 않는다.
- 각 본문 바로 아래 근거 시각자료를 배치한다. 후보는 동·층의 짧은 목록과 확인된 공통 조건으로 설명할 수 있다.
- 아파트/빌라 도식은 유형에 맞게 그리고 확인한 층 범위·향·방·욕실을 표시한다. 그림이 실제 외관/평면도를 뜻하지 않도록 짧게 밝힌다.
- 가격 범위는 범위선, 개별 거래는 점, 월별 변동은 공통 축, 자금 항목은 표·막대·흐름으로 표현한다. 모든 비교 축·단위·기간·표본·계산 기준을 표시한다. 막대축은 0을 포함한다.
- 실거래·호가·공시가격·통계·고객 입력·가정을 혼합해 임의 시세를 만들지 않는다. 중간 가격은 중앙값인지 설명한다. 등록 광고 수를 주택 수로 바꾸지 않는다.
- 면적·층·시기·입주 안내 차이는 비교에 필요한 만큼 밝힌다. 광고상의 입주 안내를 확정한 인도일로 쓰지 않는다.
- 결론은 고객 질문에 답한다. 추가자료 요청으로 답변을 대신하지 않는다. 별도 한계 페이지나 고정 페이지 수를 강제하지 않는다.
- HTML 원고와 PDF의 텍스트·그림 숫자를 대조한다. 스크립트의 PASS는 자연어 해석까지 검증했다는 뜻이 아니다.
- 정식 사례는 14종 기준본을 사용한다. P01 최신 A, P02 105동의 고객 입력 출처, P04 다른 층 가격비교 제외, P12 확인된 구성만, P13 공개 임대현황 범위를 특히 유지한다.
