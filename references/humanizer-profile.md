# EZIWORK 고객 설명형

확인한 답부터 설명한다. 구체적 가격·비교 매물·조건으로 이어가며 원래 고객 질문에 답한다. 번역체·명사형·내용 없는 강조와 제작 과정 설명을 다듬는다. 단어 목록으로 일괄 치환하지 않는다.

사용자가 선택한 제목·문장·시각화는 기본 보존한다. P01의 ‘예산 35억원 정도’를 절대 상한으로 만들지 않는다. ‘즉시입주 협의 가능’은 확정 입주일이 아니다. ‘등록 안내’는 직접 확인한 사실로 바꾸지 않는다. 과거 공고·제안·계산 가정은 현재 계약조건이나 실적이 아니다. 금액·날짜·고유명사·근거 링크·부정·가능성·비교 범위를 보존한다. 법률·계약 원문을 비격식화하거나 생략하지 않고 고객 설명 문장에만 적용한다.

제목부터 캡션까지 읽는다. 자연스러운 문장은 유지한다. 자료 없는 조망·권리·수익을 새로 꺼내 ‘알 수 없다’로 끝내지 않는다. 고객이 실제 제시된 수치를 오독하지 않도록 하는 기준일·표본·호가/거래 구분은 짧게 남긴다. 노란 강조를 의미 강도나 투자 권고로 바꾸지 않는다.

사용자가 요청한 보고서 형식에 따라 교정문만 고객 문서에 넣는다. 원본 humanizer의 결과 양식은 고객 본문에 삽입하지 않는다. 내부 `copy-review.json`에는 skill/commit, input/output 해시, 읽은 지침, 검토 범위, 보호 표현, 변경 전후·이유, 의미 검토자를 남긴다. 변경이 없으면 이유를 기록하며 실행하지 않은 검토를 PASS로 만들지 않는다. 사실·수치 재대조에서 의미 변화가 발견되면 해당 교정을 되돌린다.
