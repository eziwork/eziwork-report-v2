# 추가 자료 요청과 개인정보 사전 안내

P07·P09·P10·P12·P13은 필요한 자료가 있으면 분석을 보완하도록 선택 첨부를 요청한다. 개인정보가 포함된 자료는 보내지 않도록 첨부 요청 전에 알린다. 동봉 검사는 일부 텍스트 신호를 탐지하며 완전한 개인정보 탐지나 자동 삭제를 보장하지 않는다.

## 요청 시점과 진행

1. 고객 질문과 기존 첨부를 먼저 확인한다. 공개 자료로 조회 가능한 내용은 먼저 수집 계획에 넣는다.
2. 고객이 요청한 분석에 실제로 필요한 추가 항목만 고른다. 아래 유형별 목록 전체를 일괄 요구하지 않는다.
3. 개인정보 안내를 먼저 보여주고, 필요한 항목·분석 효과·자료가 없을 때 가능한 범위를 한 번에 설명한다. CSV·JSON·개인정보를 제거한 텍스트 PDF·필요한 값의 직접 입력을 받을 수 있다. Excel은 필요한 항목만 새 CSV로 내보내도록 안내한다. 이미지 PDF는 원본 복사 전에 개인정보 없는 텍스트 정리표로 대체하도록 요청한다.
4. 응답을 기다리는 동안 독립적인 공개 자료 조사는 진행할 수 있다. 침묵을 자료 없음이나 첨부 동의로 간주하지 않는다. 사용자가 자료 없이 진행하겠다고 하면 현재 근거로 답할 수 있는 분석을 작성하고 같은 요청을 반복하지 않는다.
5. 자료가 없으면 해당 자료가 필요한 계산·판단만 보류한다. 고객이 요청한 핵심 분석을 못 하는 경우 제공 범위를 짧게 알린다. 자료가 없는 주제를 본문에서 장황하게 설명하거나 가정값을 실제값으로 채우지 않는다.
6. 새 자료를 받으면 대상·기간·단위·출처·누락·합계를 검토한 뒤 관련 분석과 시각화만 갱신한다. 기존 승인 문장도 사실이 달라지면 그대로 유지하지 않고 변경 근거를 기록한다.

## 모든 첨부 요청 앞에 붙일 문구

> 첨부 전에 확인해 주세요. 이름·전화번호·주민등록번호·계좌번호·서명·도장 등 개인정보가 들어 있는 원본은 보내지 마세요. 필요한 항목만 별도 표로 정리하거나, 개인정보를 제거한 사본을 보내주세요. 제거 여부가 확실하지 않으면 파일 대신 아래에서 요청하는 금액·기간·조건만 입력해 주세요.

- 임차인·소유자·직원 이름은 요청하지 않는다. 세대별 자료는 A세대·B세대처럼 임의 코드로 연결하고, 실명·호실과의 대응표는 받지 않는다. 코드 치환만으로 완전한 익명화가 됐다고 보장하지 않는다.
- 분석 대상 부동산을 식별하는 공개 주소·필지와 무관한 개인 거주지·연락처를 구분한다. 개인 신분증, 서명란, 통장·개별 이체 내역 전체를 요청하지 않는다.
- 고객·직원별 매출·급여 내역 대신 월별·항목별 합계를 우선 요청한다. 등기·계약 자료는 분석에 필요한 비식별 발췌나 정리표를 우선한다.
- 검은 도형을 덮은 파일은 원문 텍스트가 남을 수 있다. 문서 본문뿐 아니라 숨김 시트·메모·파일명 등도 확인하도록 안내하되, 제거가 어렵다면 필요한 값만 직접 입력하도록 한다.
- 사용자가 실수로 개인정보가 담긴 파일을 보내면 발견한 값을 답변에 재인용하거나 보고서·샘플·공개 저장소로 옮기지 않는다. 해당 파일의 추가 처리를 멈추고 개인정보 없는 정리표나 사본을 요청한다. 이미 전송된 파일을 시스템에서 삭제했다고 주장하지 않는다.
- 사용자 자료를 추가 외부 서비스에 자동 업로드하지 않는다. 원본·추출문·세대별 운영자료는 GitHub 배포 예시에 포함하지 않는다.

## 유형별로 고를 자료와 요청 문구

### P07 상가 임차·출점

- 요청할 자료: 보증금·월세·관리비·권리금 등 제안 조건, 예정 업종·면적·영업시간, 월 인건비·기타 고정비 합계, 매출원가율, 시설 견적 합계와 필요한 비식별 평면도.
- 효과: 초기 필요자금, 월 고정비, 입력한 비용을 기준으로 한 손익분기 매출 계산. 수요·실제 매출은 별도 근거가 있어야 하며 손익분기 계산을 매출 예측으로 표현하지 않는다.
- 요청 문구: “초기 비용과 매달 필요한 매출을 더 구체적으로 계산하려면 임대 조건표와 예상 비용이 도움이 됩니다. 보증금·월세·관리비·권리금, 월 인건비 합계와 매출원가율 중 알고 계신 항목을 보내주세요. 자료가 없으면 확인된 임대 조건과 공개 상권자료를 중심으로 작성하겠습니다.”

### P09 토지 매수·이용조건

- 요청할 자료: 계획한 사용 목적, 보유 중인 토지이용계획·지적 관련 자료의 비식별 사본, 도로·진입 조건 자료, 관계기관 회신의 필요한 부분과 발급일. 공개 조회로 확보한 자료는 다시 요청하지 않는다.
- 효과: 필지·면적·용도지역·도로 조건 대조, 계획한 이용과 관련된 확인 항목 구체화. 자료가 있어도 개별 인허가 가능성을 확정하지 않는다.
- 요청 문구: “어떤 용도로 사용할 계획인지와 진입로 관련 자료, 관계기관에서 받은 답변이 있으면 보내주세요. 공개 조회로 확인되는 자료는 제가 수집하고, 추가 자료는 해당 필지의 이용 조건을 살펴보는 데 반영하겠습니다.”

### P10 개발사업성 예비검토

- 요청할 자료: 계획 용도·면적·세대수, 토지비·공사비·설계비·기타 사업비, 일정, 자금조달 금액·금리·기간, 분양·임대 계획의 금액과 산출 근거. 견적·계획의 작성일과 부가세 포함 여부도 확인한다.
- 효과: 항목별 수지, 현금 투입 시점, 공사비·금리·일정 변화에 따른 계산. 계획·견적·계약 금액과 실제 지출을 구분한다.
- 요청 문구: “계획 면적과 사업비·일정 자료가 있으면 수익과 자금 투입 시점을 더 구체적으로 비교할 수 있습니다. 개인정보를 제외한 사업비 표나 항목별 금액을 보내주세요. 아직 정하지 않은 값은 비워두셔도 됩니다.”

### P12 다가구·임대주택 건물 전체 매수

- 요청할 자료: 임의 세대코드별 보증금·월세·계약 종료월·공실 여부, 월별 운영비 합계, 수선비 내역의 항목·금액, 필요한 경우 이름 등을 제거한 권리관계 발췌. 같은 코드를 유지하고 실명·실제 호실 대응표는 받지 않는다.
- 효과: 임대수입·운영비·공실 현황, 보증금 합계와 계약 종료 시기 비교. 정리표만으로 임차권 우선순위·권리 안전성·보증금 회수 가능성을 판단하지 않는다.
- 요청 문구: “건물 전체의 임대수입과 보증금 규모를 비교하려면 세대별 임대 현황이 도움이 됩니다. 이름과 연락처, 실제 호실 대신 A세대·B세대로 표시하고 보증금·월세·계약 종료월·공실 여부만 정리해 주세요. 운영비와 수선비는 항목별 합계로 보내주시면 됩니다.”

### P13 임대자산 월간 운영

- 요청할 자료: 대상 월과 비교 월의 세대코드별 청구액·수납액·이월 미수금·당월 말 미수금, 공실 현황, 항목별 지출·수선비 합계, 필요한 보증금 증감 별도 합계. 개인별 통장 거래내역이나 계좌번호는 요청하지 않는다.
- 효과: 월별 수입·지출·미수금·공실 변화 비교. 발생 기준과 현금 수납 기준을 구분하고 보증금 유입을 임대 매출에 합산하지 않는다. 합계가 맞지 않으면 불일치 부분만 확인한다.
- 요청 문구: “이번 달 수입·지출과 미수금 변화를 정리하려면 이번 달과 비교할 달의 운영표가 필요합니다. 임차인 이름·연락처·계좌번호 없이 청구액·수납액·미수금·공실과 지출 합계를 보내주세요. 원본 장부 대신 필요한 항목만 정리한 표도 가능합니다.”

## 자료 사용 범위

- 정리표는 사용자 제공 자료로 표시하고, 원본을 보지 않았으면 원본 대조 완료로 기록하지 않는다. 출처명·기준월·작성일·단위를 남긴다.
- 실제값과 고객의 예상값을 분리한다. 필수 계산값이 비어 있으면 0으로 바꾸지 않는다.
- 자료가 충분한지 판단하는 과정에서 개인정보 원본 제출을 조건으로 삼지 않는다. 개인 식별이 필요한 판단은 이 접수 경로의 지원 범위에서 제외한다.
- 추가 자료를 받았다는 사실만으로 분석 정확도나 품질 향상을 보장하지 않는다. 검토를 통과한 항목에 한해 분석 범위를 넓힌다.
