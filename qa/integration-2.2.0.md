## 검증 대기와 구분

- macOS 실제 실행 환경이 없어 실행하지 않았습니다. Windows/macOS CI 정의는 있지만 이 작업에서 GitHub Actions를 실행하지 않았습니다.
- 모바일 브라우저 화면은 직접 검토하지 못했습니다. 반응형 스타일 존재를 모바일 검증 완료로 표시하지 않습니다.
- 새 거래·광고·계약 원본을 수집하지 않았습니다. 기존 사례의 근거 범위와 원래 기준일은 유지합니다. 토지이용·공시지가·지적도는 이번 지도 성공과 별개입니다.
- 일부 사례는 공개 과거 자료와 명시된 가정만으로 설명합니다. 실제 고객 계약·재무 자료가 있어야 가능한 분석의 검증 완료를 뜻하지 않습니다.
- 전체 고객 품질·사용자 최종 승인은 자동 검사로 대신하지 않습니다. 기존 승인 상태는 그대로입니다.
- 이전 수집 성능 기록은 `live-performance.json`에 보존합니다. 이번에는 14종 출력과 부분 수정 재출력을 수행했으며, 전체 신규 수집·캐시 성능을 다시 측정했다고 주장하지 않습니다.

## 근거 추적

각 예시의 `integration-2.2.0/`에는 원본 파일 해시·JSON 포인터·실행 도구·교정 변경 이유를 둡니다. `chart-data.json`은 보존 원자료의 필요한 수치만 뽑은 공개 재생용 표이며 새로 수집한 데이터셋이 아닙니다. `chart-spec.json`으로 이 표를 다시 그릴 수 있습니다. 전체 원자료·고객 파일·개인 경로는 공개본에 넣지 않습니다. 지도 원본 PNG/좌표 응답과 조회일은 보존합니다.

원본 버전과 라이선스: `references/integrations-lock.json`, `THIRD_PARTY_NOTICES.md`. 예시 비교: [14종 목록](../examples/integration-2.2.0.html).
