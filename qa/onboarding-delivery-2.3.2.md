# 2.3.2 인증 입력·보고서 완료 검증

검증일: 2026-10-10. 자동시험 총 153개(워크플로·설정·완료 102개 + 수집 51개) 통과. skill-creator quick_validate 통과.

## 실제 Windows 실행

- 배포 파일을 기존 저장소 바깥의 별도 프로젝트로 복사하고 새 Python 프로세스에서 실행. 프로세스의 5개 키 변수를 제거해도 Windows 사용자 저장소의 5개 값 인식. ensure는 입력 창이나 재입력 없이 종료. 실제 키값은 출력·변경하지 않음.
- runtime/node_modules가 없는 별도 복사본 doctor는 DEPENDENCIES_REQUIRED, ready=false, 종료 코드 2. 초기 대조 폴더가 원본 저장소 아래에 있어 Node의 상위 node_modules를 찾는 것을 확인하고, 저장소 밖 복사본으로 재시험.
- Windows 새 콘솔 생성 경로를 실제 실행. 표준 입출력이 TTY임을 확인하고 합성 문자 시퀀스로 별표·글자 수 입력을 실행. 실제 키 저장 및 사람의 Ctrl+V 조작을 대신하는 시험은 아님.
- 한글·공백 경로에서 작업 시작 → 원고 연결 → HTML·PDF 3쪽 생성 → 완료 검사. 앞표지·본문·끝표지 화면과 100/70/차이30 합성값을 확인. 고객 자료나 실제 시세 분석 아님.
- 다른 합성 HTML을 기존 PDF에 연결한 CLI finish는 종료 코드 2, OUTPUT_FILES_CHANGED_REGENERATE_PDF. 원고/요청 변경, 파일 삭제, 렌더링 도중 입력 변경 등은 자동시험에서 차단 확인.

## 주요 자동시험

현재 프로세스 값의 지속 저장, 과거 로컬 값 이전, 등록 완료 시 창 미실행, 명시적인 키 교체, Windows 실행 인수에 키 미포함, macOS 셸 경로 인용, 별표·입력 글자 수·백스페이스, 비대화형 입력 차단, 취소 후 재개, 요청과 원고 불일치, 출력 기록 없음, 다른 HTML/PDF 조합, 수정 후 완료 무효화, 기존 자료·표지·14종 합성 출력 회귀를 포함한다.

## 유지되는 검증 한계

동일 Windows 사용자·Python 환경에서의 격리 폴더/프로세스 시험이며 새 OS 시험이 아니다. macOS는 모의시험으로 실제 단말 시험은 하지 않았다. 새 Codex 대화의 모든 자연어 수행을 보장하지 않는다. 작업 명령을 실행하지 않는 에이전트를 스크립트가 강제로 이어 실행시킬 수는 없다. SKILL.md에 시작·재개·최종 완료 절차를 연결했다.

출력 기록은 현재 입력과 파일 해시를 연결한다. 원고의 자연어 의미, 맞춤 HTML과 계약의 의미 일치, 투자 적합성 또는 시각 품질 전체를 자동으로 증명하지 않는다. 실제 내용·시각 검토 후에만 --reviewed를 사용한다. 이번 검증은 신규 API 호출·실제 고객 자료 업로드·14종 PDF 전면 재생성을 포함하지 않는다.
