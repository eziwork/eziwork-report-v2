# 2.3.0 키 등록 검증

5개 키는 현재 Windows 사용자 환경변수에서 확인했습니다. 값은 기록하지 않습니다. 공공데이터포털 기존 로컬값 이전, VWorld·ECOS 터미널 등록 후 재조회, 나머지 저장값 확인을 수행했습니다. 등록 여부와 서비스 인증 성공은 구분합니다.

자동시험은 누락·취소·재개·저장 실패·충돌·로컬 이전·Mac 전용 저장소·값 비노출을 검사했습니다. Mac 저장 코드 시험은 Windows에서 OS 분기를 모의한 결과이며 Mac 실기 검증이 아닙니다. Mac 파일 권한 검사는 실제 Unix 환경에서 추가 실행해야 합니다.

key-env check와 doctor는 인증 서버를 호출하지 않습니다. 키 교체는 해당 사용자 저장소에서 수행하고, 현재 프로세스에 이전 값이 있으면 앱을 다시 실행합니다. 현재 프로세스 값을 몰래 덮어쓰지 않습니다.

상세 결과는 [2.3.0 검증표](migration-2.3.0.md)를 참조합니다.
